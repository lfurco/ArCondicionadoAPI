## Atualização do Projeto

O projeto foi adaptado para o tema **Manutenção de Ar-Condicionado**, mantendo a mesma estrutura utilizada anteriormente.

Atualmente é possível:

- Cadastrar serviços
- Listar todos os serviços cadastrados
- Buscar um serviço por ID
- Atualizar informações
- Remover registros
